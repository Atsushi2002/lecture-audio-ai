# 講義音声ノートAI

講義の録音を入れると、**文字起こし・要約（3行）・要点（3〜5個）** を自動で作るスマホ対応Webアプリです。
研修課題5（DAY5）成果物。

サーバー不要のフロントエンドのみ（HTML / CSS / JavaScript）。GitHub Pages でそのまま公開できます。

---

## 使い方（3ステップ）

1. **APIキーを入れる**
   [Google AI Studio](https://aistudio.google.com/apikey) でGemini APIキーを取得し、アプリの「1. APIキー」に貼って「この端末に保存」。
   → 不安なときは **「接続テスト」** を押す。`接続OK` が出れば準備完了。
2. **音声を入れる**
   講義名（任意）を入れて、音声ファイルを選択。**まずは30秒〜2分の短い音声**で試してください。
3. **実行**
   「文字起こし＆要約を実行」を押すと、文字起こし → 要約 の順に表示されます。それぞれコピーできます。

## セットアップ

### A. ローカルで動かす

`index.html` をブラウザで開くだけです（ビルド不要）。

`file://` でクリップボードAPIが制限される環境があるため、簡易サーバー経由が確実です。

```bash
cd day5-lecture-audio-ai
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

### B. GitHub Pages で公開する

1. GitHub で新規リポジトリを作成
2. このフォルダの中身をアップロード（ドラッグ&ドロップでOK）
3. リポジトリの **Settings → Pages**
4. Source: `Deploy from a branch`、Branch: `main` / `/(root)` を選んで **Save**
5. 数分後に出るURLをスマホで開いて動作確認

> APIキーはコードに書かれていないので、そのまま公開して問題ありません。

## 対応している音声形式

`wav` / `mp3` / `aac` / `ogg` / `flac` / `aiff`
（[公式の対応形式](https://ai.google.dev/gemini-api/docs/audio)）

- **`.m4a` は非対応**です。iPhoneのボイスメモは m4a なので、mp3 か wav に変換してください。
- ファイルサイズ上限は **15MB**。インライン送信はリクエスト合計20MBまでで、base64化で約1.33倍に膨らむための余裕です。
- 上限を超える場合は音声を分割するか、Files API 対応に作り替えてください。

## 使用モデル

既定は **`gemini-3.5-flash`**（公式の音声理解ガイドのサンプルと同じモデル）。
「詳細設定」から `gemini-3.6-flash` などに切り替えられます。

モデル名はすべて [公式Models一覧](https://ai.google.dev/gemini-api/docs/models) から取得したものです。
`gemini-1.5-*` や `gemini-2.0-*` は現在使えません（AIが提案してきても使わないこと）。

---

## APIキーの扱い（重要）

- キーは **コードに直書きしていません**。ブラウザの `localStorage` にのみ保存されます。
- 保存先はその端末のブラウザだけ。こちらのサーバーには何も送信されません。
- 共用端末では、使い終わったら **「削除」ボタン** を押してください。
- このアプリはブラウザから直接 Gemini API を呼ぶ構成のため、**キーは開発者ツールから見えます**。
  自分専用の利用を前提としています。不特定多数に配る場合は、サーバー（Cloud Run 等）を挟んでキーを隠す設計に変更が必要です。
- **個人情報・機密を含む音声はアップロードしないでください。**

## テスト

```bash
npm install jsdom
node tests/smoke.test.mjs   # → PASS 44 / FAIL 0
```

`fetch` をモックに差し替え、実際のAPIを叩かずにリクエストの中身を検証します。
スマホ実機での確認は `docs/TESTCASES.md` を使ってください。

## 設計上のポイント

- **文字起こしと要約を別リクエストに分けた** … どちらで失敗したか切り分けやすい
- **「接続テスト」ボタン** … 公式トラブルシュートの「まずテキストだけで通す」を1タップで実行できる
- **エラーはレスポンス全文を画面に出す** … AIに相談するときそのまま貼れる（スクショではなくテキストで渡すのが速い）
- **拡張子からMIMEを決める** … ブラウザの `file.type` は環境差が大きく、`audio/mpeg` など公式リストに無い値を返すことがある
- **文字起こしは `temperature: 0`** … 創作を防ぐ

---

## 詰まったときは

1. まず **「接続テスト」** を押す
   - 失敗 → APIキーかネットワークの問題（キーの前後の空白に注意）
   - 成功 → 音声側（形式・サイズ・長さ）の問題
2. エラー詳細を開いて **全文をコピー**
3. `docs/STATUS.md` を更新し、エラー全文と [公式URL](https://ai.google.dev/gemini-api/docs/audio) を添えてAIに相談

よくあるHTTPステータスの意味は `docs/API_NOTES.md` の「4. エラーの読み方」にまとめてあります。
