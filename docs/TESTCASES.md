## 0. 自動テスト（APIキー不要・実施済み）

`fetch` をモックに差し替え、Gemini APIに送るリクエストの中身を検証する自動テストを用意しています。

```bash
npm install jsdom
node tests/smoke.test.mjs
```

**結果: PASS 44 / FAIL 0（2026-08-04 実施）**

エンドポイント・認証ヘッダ・MIME変換・サイズガード・エラー表示など、
「実機で試す前に潰せるもの」はここで潰しています。詳細は `tests/README.md`。

以下の A〜C は、**自動テストでは確認できない実機・実APIの観点**です。合格判定にはこちらが必要です。

## 事前準備

- 端末A: スマホ（iOS Safari または Android Chrome）※合格判定の主対象
- 端末B: PCブラウザ（デバッグ用。DevTools のコンソールとネットワークを開いておく）
- テスト音声1: 30秒程度の mp3（自分の声で「今日は情報理論の第5回です…」など読み上げ）
- テスト音声2: 対応外の m4a ファイル
- テスト音声3: 15MBを超えるファイル（無ければ長い音楽ファイルで代用）
- 有効なGemini APIキー

> ⚠️ 個人情報・機密を含む音声は使わないこと。スクショにキーや個人情報を写さないこと。
