# screenshots/

動作証跡のスクリーンショットをここに置きます。
`docs/TESTCASES.md` の「証跡」欄のファイル名に合わせてください。

## 合格判定に必要な4枚（最低限）

| ファイル名 | 内容 |
|---|---|
| `01_top_mobile.png` | スマホでトップ画面（レイアウトが崩れていない） |
| `04_transcript.png` | 文字起こしが表示されている |
| `05_summary.png` | 要約と要点が表示されている |
| `06_copy_toast.png` | 「コピーしました」のトーストが出ている |

## あると良い追加分

`02_key_saved.png` / `03_connection_ok.png` / `07_copy_summary.png` /
`11_unsupported.png` / `13_invalid_key.png` / `14_old_model_404.png`

## ⚠️ 撮る前に確認

- **APIキーが写っていないこと**（キー欄は「表示」を押さずマスクのまま撮る）
- 個人情報・機密が写っていないこと（講義名、音声内容、通知バナー、ブラウザのタブ名も注意）
- スマホのスクショは幅750px程度に縮小するとリポジトリが軽くなります
